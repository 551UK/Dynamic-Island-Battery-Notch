## Features

- A coloured outline shows how much battery you have left. It gets shorter as the battery drains.
- Automatic green, yellow and red colours, or your own custom colour.
- Custom charging colour with optional gentle pulsing.
- Hides the battery outline during phone calls and CallKit-integrated voice calls, restoring it when the call ends.
- Adjustable thickness from 1.5 pt.
- Automatically fits the Lock Screen and the screen-recording countdown and recording display.
- Hides the original white Dynamic Island border and matches the Lock Screen padlock colour.

## Compatibility

**iPhone 14 Pro Max · iOS 16 · Dopamine rootless**

Install the latest DEB from [GitHub Releases](https://github.com/551UK/Dynamic-Island-Battery-Notch/releases) with Sileo, then respring.

**Known-good fallback:** [v0.2.14](https://github.com/551UK/Dynamic-Island-Battery-Notch/releases/tag/v0.2.14) is preserved in the [stable working-base branch](https://github.com/551UK/Dynamic-Island-Battery-Notch/tree/stable/v0.2.14-working-base).
