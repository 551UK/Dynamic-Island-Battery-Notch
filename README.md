# Dynamic Island Battery Notch

A battery-level outline for **iPhone 14 Pro Max, iOS 16 (Dopamine rootless)**.

- Automatically follows the Dynamic Island during music, timers, screen recording, calls and other activities.
- Shows battery progress in 1% increments, with automatic red/yellow/green or custom colours.
- Colours the Lock Screen padlock to match the battery indicator, including while charging.
- Supports a separate charging colour, optional charging pulse and independent normal/charging line thickness.
- No recording/call-specific size overrides, delayed hiding or diagnostic controls.
